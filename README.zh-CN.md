## 认识 Simplex

把你的资料、项目和工具接进来，让 AI 接着你的背景做事。

**Another Me** 是你的个人助手。它读取你的 Profile，在需要时查回过去的决定和项目资料，记下值得继续跟进的事情。遇到需要不同角色配合的工作，你可以让它邀请其他 Agent 进入同一个 Room，一起讨论、分工和交付。

Agent 在你连接的电脑上执行，使用本机文件、命令行和已有的运行环境。对话、协作约定、运行活动和成果留在同一个工作空间里，方便接着推进。

## 看看它如何工作

### 了解你，从你已经留下的资料开始

**看看 AI 眼中的你。**

上传简历、笔记和介绍材料，选择已授权的应用资料，或带入另一位 AI 对你的总结。Simplex 将这些信息整理成一份个人 Profile：经历时间线、沟通风格、工作方式、偏好和写作风格。

这份 Profile 也是 Another Me 理解你的背景。补充新的资料时，它会结合已有内容更新，让接下来的交流少一些重复介绍。

项目、对话和文件还可以积累成 Personal Wiki，按项目、主题、人物和公司组织。需要继续旧工作时，Another Me 可以检索已有背景，查回相关原文。

> 接着上次那个项目，先找回已经确定的方向和还没解决的问题。

### 主动跟进，让聊过的事情有下文

**你说过要做的事，它会接着留意。**

Another Me 可以从交流中识别承诺、截止日期、待办和等待回复的事项，记下来，并安排合适的时间继续检查。你也可以直接在 Room 中设置 Routine，让它按约定的节奏工作。

启用主动提醒并连接受支持的应用后，新的邮件、日历变化和消息也能成为跟进线索。它会判断哪些事情值得现在告诉你、哪些留待后续处理，并结合你的反馈调整提醒方式。

> 周五要给朋友演示这个项目。周四晚上帮我检查准备情况，先把已有材料和待确认的问题整理出来。

到点后，Another Me 继续检查和整理，再带着结果来找你。你可以在对话里调整要求，也可以从 Room 侧栏管理例行事项。

### 给你的 Agent 拉个群

**交代一个目标，让不同角色互相接力。**

让研究、开发、写作或评审 Agent 进入同一个 Room，围绕同一份材料协作。Another Me 可以查找你可用的 Agent，发起协作 Room 的创建请求；确认后，项目资料和工作说明一起进入新群。

在 Room 中，Agent 可以分配明确任务，把结果交给下一位接收者，或将问题交回协调者。你随时可以加入讨论、补充要求，让团队接着推进。

> 开个群准备这次内测。先梳理演示流程，再做一个能打开的页面，最后检查一遍。

打开侧栏的 **Collaboration**，可以看到团队约定的角色、交接和汇报关系；通过 **Activity** 查看 Agent 的实际运行过程。成果以文档或文件回到 Room，点开预览、继续修改，也能在 Library 中整理和查找。

## 在自己的设备上，按自己的方式运行

| 你能选择什么 | 在 Simplex 中怎么做 |
|---|---|
| 自己运行 | 自托管工作空间，将 Agent 接到自己的 Local Computer，使用本机文件、CLI 和已有登录态。 |
| 自己的模型与运行方式 | 为 Agent 选择 Computer、Runtime 和可用模型；支持 Codex、Claude Code 与 Pi，模型目录取决于对应运行环境的配置。 |
| 自己的 Agent 团队 | 在对话中设定角色与工作要求，调整 Agent，组合适合当前项目的协作方式。 |
| 自己的工具与 Skills | 复用本机工具和受支持的 Skills，按需求扩展个人工作流程。 |
| 自己改造 | 通过开源代码理解和调整个人助手、工具接入与协作机制。 |
