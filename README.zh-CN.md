# SimplexAI

**开源、本地优先的个人 AI。**

[English](./README.md) · **简体中文**

## 简介

SimplexAI 让你的电脑成为个人 AI 的工作环境。它连接本机资料、工具和已有的 Agent Runtime，让 AI 能查回项目背景、执行任务，并留下可以继续修改的成果。

**Another Me** 是你的个人助手：通过 Profile 和个人 Wiki 了解你，记下值得跟进的事情；需要配合时，组织其他 Agent 进入同一个 Room，分工、交接和评审。

从“接着上次的项目”到“周五演示前帮我检查准备情况”，你可以在同一个地方交代目标、看进展、补充要求，再打开最终文件。

## 能做什么

- **用自己的电脑做事。**直接使用本机文件、命令行工具与登录态，接入已有的项目环境。
- **接上你的背景。**Profile 整理经历与偏好，个人 Wiki 保留项目知识和原文，继续工作时少重复解释。
- **把事情跟下去。**记录承诺、待办和截止日期，按计划检查，在值得关注时主动提醒。
- **让 Agent 一起做事。**研究、开发、评审在同一个 Room 分工交接，你随时可以补充要求。
- **拿到能继续用的成果。**文档和文件留在工作空间，直接预览、修改和保存，下次接着做。

## 本地优先

自托管工作空间，Agent 在自己的电脑上运行，使用本机文件、工具与登录态。支持 Codex、Claude Code 和 Pi。

云端模型与应用按配置调用外部服务。
