# SimplexAI

**开源、本地优先的个人 AI。**

[English](./README.md) · **简体中文**

## 本地优先

自托管工作空间，Agent 在自己的电脑上运行，使用本机文件、工具与登录态。支持 Codex、Claude Code 和 Pi。

云端模型与应用按配置调用外部服务。
