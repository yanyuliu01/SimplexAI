## 简介

SimplexAI 把**你的资料、工具、本地模型服务和 Agent 运行环境**接到一起，组成可以自行部署的个人 AI 工作空间。已有的项目环境可以直接参与任务，以前的决定能查回，做出的成果可以继续修改。

**Another Me 是你的个人助手。**它通过 Profile 和个人 Wiki 了解你的背景，跟进值得留意的事项；需要不同角色配合时，组织其他 Agent 进入同一个 Room。你在同一个地方看进展、补充要求、打开成果。

> “接着上次的项目，周五演示前帮我检查准备情况，再叫研究和开发 Agent 一起把演示做出来。”

## 能做什么

- **Agent 与模型都能本地运行。**部署本地模型服务，使用本机文件、命令行工具与登录态。
- **接着上次的项目。**Profile 和个人 Wiki 带回偏好、项目知识和以前的决定，少重复解释。
- **主动跟进下一步。**记录承诺与截止日期，按计划检查，在有事值得关注时主动找你。
- **把 Agent 拉进同一个群。**研究、开发、评审分工交接，你随时可以加入讨论、调整要求。
- **成果留下来，下次接着用。**文档、原型和其他文件保存在工作空间，直接预览、修改与继续。

## 本地优先

**工作空间自己部署，模型服务本地运行，Agent 在自己的电脑上执行。**

提供 **LLM 推理、Embedding 和 Rerank** 本地模型服务，支持按硬件资源规划、部署、接入与状态检查。

接入自己电脑上的 Codex、Claude Code 或 Pi，复用本机工具和受支持的 Skills，并选择对应 Runtime 中可用的模型。

本地执行与自托管由你掌握。使用云端模型或外部应用时，请求仍会发送给对应服务。
